# MVP Scope

## Included in MVP
- Upload chess position screenshot.
- Backend upload endpoint.
- Board/FEN response contract.
- Interactive analysis board.
- Edit mode for correcting detection errors.
- Copy FEN.
- Open position in chess.com analyzer.
- Shareable position link.
- Basic public position page.
- Real detection pipeline after mock flow works.
- Basic analytics/logging later in hardening block.

## Explicitly not included in MVP
- User accounts.
- Saved collections.
- Public collections.
- Payments/subscriptions.
- Internal Stockfish engine analysis.
- Best move suggestions.
- SEO/programmatic pages.
- Competitions/leaderboards.
- Mobile apps.

## MVP success criteria
A user can upload a screenshot, get a usable board/FEN, correct the board if needed, and send the position to chess.com or share it by link.
