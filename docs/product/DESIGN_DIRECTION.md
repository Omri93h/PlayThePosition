# Design Direction

Play That Position should feel like a modern, premium, clean web app with its own identity. It should be chess-inspired, but not a copy of chess.com, lichess, or other chess products.

## Principles
- Dark-first interface.
- Strong centered upload experience.
- Board-first layout in later blocks.
- Restrained green accents.
- Clean typography.
- Spacious layout, rounded cards, and subtle shadows.
- Mobile-responsive from the start.

## Avoid
- Cheap gradients.
- Cluttered layouts.
- Cartoonish visuals.
- Random accent colors.
- Chess clichés as decoration.
- Building native/mobile app behavior before the MVP web app is complete.

## Future
Native and mobile apps can be considered after the MVP. Do not optimize architecture or UI scope around native/mobile app needs during current MVP work.
