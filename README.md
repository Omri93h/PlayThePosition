# Play The Position — Codex Starter

A Codex-ready starter workspace for building Play The Position.

Product:
Upload a chess position screenshot and turn it into a live, editable, analyzable chessboard.

## How to start with Codex

1. Open this folder in Codex.
2. Ask Codex to run/read `prompts/ONBOARDING_PROMPT.txt`.
3. Verify that Codex understands the product, MVP, blocks, and current feature.
4. Ask Codex to run/read `prompts/PLAN_PROMPT.txt`.
5. Approve or adjust the plan.
6. Ask Codex to run/read `prompts/EXECUTE_PROMPT.txt`.
7. Review results and move to the next feature.

Do not ask Codex to “build the whole app”. Work block-by-block and feature-by-feature.
